《main.exe 操作手册》

【1. 程序简介】
--------------------
main.exe 是一个用于“百分号数独”生成、求解与 SAT 问题转换的命令行工具。支持：
- 生成带有百分号约束的数独游戏
- 调用内置 SAT 求解器进行自动解答用户提供的cnf文件
- 支持批量处理、性能统计

【2. 快速开始】
--------------------
1. 双击 main.exe 可进入交互菜单，按提示操作。
2. 推荐用命令行运行，支持更多参数和批量处理。

【3. 常用命令与玩法】
--------------------
1. 生成并玩数独
   - 运行：
     main.exe
   - 按菜单选择“生成百分号数独”或“游玩数独”或“查看答案”
   -首次游玩请选择“生成百分号数独”
   - 程序支持“手动输入”或“自动求解”来体验解题。

2. 求解数独（SAT 方式）
   -游玩时可以输入”0 0“查看答案
   -数独主界面可以直接选择“查看答案”来查看答案
   -首先输入需要插入的行数及列数（如 ：3 3 ——第三行第三列）
   -输入需要插入的数字（如：5）

3. 对cnf文件求解
   - 支持批量处理 test 目录下的多个 .cnf 文件，自动输出结果和性能统计。
   - 示例：
     main.exe test\1.cnf
     main.exe test\*.cnf

4.保存求解文件（*.res）
   - 输入1来实现文件保存，后续可以结合cnf文件验证结果
   -自动保存以后将会回到主界面

【4. 输入输出文件说明】
--------------------
- .cnf：标准 DIMACS 格式，第一行为“p cnf 变量数 子句数”，后续为子句（以0结尾）。
- .res：SAT 求解结果，格式为“SAT/UNSAT”及变量赋值。
- percent_sudoku.cnf：自动生成的百分号数独 SAT 文件。

【5. 命令行参数说明】
--------------------
main.exe [选项] [输入文件]
- 无参数：进入交互菜单
- 输入 .cnf 文件：自动求解并输出结果
