### 表1 district(行政区划表)
(不含港、澳、台地区)

| 字段名 | 数据类型 | 是否为空 | 码 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| id | int | NO | PRI | 编号 |
| ac | char(6) | YES | UNI | 行政区域代码 |
| v | int | YES | | 校验码 |
| prov | char(50) | YES | | 省或直辖市 |
| city | char(50) | YES | | 地市州 |
| county | char(50) | YES | | 区县 |

大陆居民身份证号的前6位，就是来自行政区域代码。

### 表2 station(车站表)

| 字段名 | 数据类型 | 是否为空 | 码 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| sid | int | NO | PRI | 编号 |
| sname | char(20) | YES | UNI | 站名 |
| city | char(22) | YES | | 所在城市 |

内地各车站的取名是统筹考虑的，没有重名的车站。为简化查询，我们适当增加了数据库的冗余，所有车站编号都替换成了站名。
省会和直辖市通常都有多个大型车站。字段city标注了每个车站位于那个城市。通常我们购买“北京”到“广州”的车票，不仅考虑“北京”站和“广州”站，“北京西”和“广州南”也是可能的选择。
注意：站名中一般都不含“站”字。

### 表4 route(车次表)

| 字段名 | 数据类型 | 是否为空 | 码 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| train_no | char(11) | NO | PRI | 车次 |
| start | char(20) | YES | MUL | 始发站 |
| dest | char(20) | YES | MUL | 终到站 |
| depart | time | YES | | 发车时间 |
| arrival | time | YES | | 终到时间 |
| day | int | YES | | 天数 |
| mileage | int | YES | | 里程 |

始发站和终到站都取自车站表(station)的sname字段。里程以公里为单位。当天到达的天数为1，次日到达的为2，依此类推。

### 表5 timetable(列车运行时刻表)

| 字段名 | 数据类型 | 是否为空 | 码 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| train_no | char(11) | NO | PRI | 车次 |
| stop_seq | smallint | NO | PRI | 站序号 |
| station_name | char(20) | YES | MUL | 站名 |
| arrival_time | time | YES | | 到站时间 |
| departure_time | time | YES | | 离站时间 |
| day | int | YES | | 天数 |
| mileage | int | YES | | 里程 |
| price | int | YES | | 票价 |

字段train_no取自route(车次表)中的train_no。station_name取自station(车站表)中的sname。

列车运行时刻表反映了每趟列车经停车站的顺序，到站时间，离站时间。始发站没有到站时间(NULL)，终到站没有离站时间。里程从始发站算起，票价也是。如果从列车的经停站上车，票价 = 终到站的票价 - 上车站的票价。

我们对实际的系统做了简化，票价只有一个等次，比较接近中间价位(约等于动车二等座)，且舍去了小数部分。

### 表6 ride_record(乘车记录表)

| 字段名 | 数据类型 | 是否为空 | 码 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| rno | int | NO | PRI | id |
| pid | int | NO | MUL | 乘客id |
| train_no | char(11) | NO | MUL | 车次 |
| rdate | date | NO | | 乘坐日期 |
| start | char(20) | NO | | 上车站 |
| dest | char(20) | YES | | 下车站 |
| car_no | smallint | YES | | 车厢 |
| seat | char(12) | YES | | 座位号 |
| price | int | YES | | 票价 |

主码rno是一个非业务数字编号。外码pid取字乘车人表(passenger)的主码pid。外码train_no取自车次表(route)的train_no。上车和下车站直接用额站名，取字车站表(station)的sname。当然上车站和下车站都受车次的约束。该次列车必须经停这两个车站。
